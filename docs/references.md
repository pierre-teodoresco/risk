# Références et direction artistique

Sélection explorée avant développement, puis validée avec l’utilisateur.

| Référence | Principe retenu |
| --- | --- |
| [Risk: Global Domination](https://store.steampowered.com/app/1128810/RISK_Global_Domination/) | Carte dominante, chiffres d’armées, joueurs visibles, phases explicites et résolution Blitz instantanée |
| [Wingspan — press kit](https://monstercouch.com/press/sheet.php?p=wingspan) | Papier ivoire, matières discrètes, palette douce |
| [Root](https://www.direwolfdigital.com/root/) | Identité illustrée et emblèmes mémorables |
| [Dune: Imperium Digital](https://www.direwolfdigital.com/dune-imperium-digital/) | Actions contextualisées et guidage de phase |
| [Hulu Watch Party — Mobbin](https://mobbin.com/screens/7623abaf-9345-4a32-91d9-302bf33cfd17) | Invitation par lien, attente des amis et lancement du salon |
| [Duolingo — Mobbin](https://mobbin.com/screens/3b616a3f-6b94-4610-b4e1-9c3508b1548c) | Étapes visibles et action principale persistante |
| [Headspace — Mobbin](https://mobbin.com/screens/9fb74046-d5b5-4af9-9204-78cacdd67661) | Formes géométriques douces et illustrations colorées |

Mappa utilise une carte SVG dessinée pour ce projet, des formes de papier découpé, une typographie éditoriale, des surfaces ivoire, une mer bleu poudre et six couleurs pastel. Les six emblèmes complètent le code couleur. Les images des jeux de référence servent uniquement à l’étude ; elles ne sont pas distribuées avec Mappa.
